# CV-reviewer AI — Internal Version

A Streamlit-based internal system for instant resume analysis. 
It uses advanced NLP models to detect issues, improve phrasing, and generate a complete candidate evaluation.

---

## Features
- Instant resume analysis
- Grammar and structure issue detection
- Automatic improvement suggestions
- Full candidate evaluation
- Clean and fast English interface

---

## How It Works
1. Upload the resume 
2. NLP models analyze the content 
3. Issues are detected and improved 
4. A detailed report is generated 
5. Final evaluation is displayed

---

## Tech Stack
- Python 
- Streamlit 
- Groq API 
- Advanced text processing
